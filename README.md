# Sistema de Gestão de Informações

Projeto universitáro criado com o objetivo de representar e documentar o fluxo de informações de uma organização comercial utilizando um banco de dados relacional

## 📌 Sobre o projeto

Temos atualmente:

- Dicionário de dados
- Diagrama conceitual

O modelo desenvolvido possui 14 entidades e representa o fluxo de informações entre diferentes áreas da organização.

## 🔄 Fluxo principal

Cliente → Pedido → Produção → Estoque → Separação de Pedido → Entrega

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- BRMW

## 🎓 Contexto

Projeto desenvolvido para fins acadêmicos durante o curso de Análise e Desenvolvimento de Sistemas.
